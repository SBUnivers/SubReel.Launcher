# SubReel — License Status UI patch

Этот патч обновляет только экран `Minecraft Java` в Account Center. Он рассчитан на проект, в котором уже установлены предыдущие патчи Supabase Auth / Account Center / License UX.

## Что меняется

- Вместо одного текстового блока появляется отдельная цветная карточка статуса лицензии.
- Статусы различаются: не проверена, проверка выполняется, лицензия подтверждена, лицензия не обнаружена, офлайн-профиль, истёкшая сессия, ошибка соединения и неизвестная ошибка.
- Ошибка сети больше не отображается как отсутствие лицензии.
- При успешном Microsoft-входе профиль проверяется и карточка становится зелёной.
- При выборе другого игрового профиля статус сбрасывается и требует новой проверки.
- Привязка SubReel остаётся отдельной от Microsoft Auth.

## Установка

1. Сделайте резервную копию проекта.
2. Распакуйте содержимое ZIP в корень решения, где находится `SubReel.Launcher.slnx`, с заменой двух файлов `AuthWindow.xaml` и `AuthWindow.xaml.cs`.
3. В корне решения выполните:

```powershell
dotnet build .\SubReel.Launcher.slnx
if ($LASTEXITCODE -ne 0) { throw "Сборка завершилась с ошибкой" }
```

## Проверка вручную

1. Откройте Account Center → Minecraft Java. До проверки должна быть нейтральная карточка «Ещё не проверена».
2. Нажмите «Войти через Microsoft». При успешной проверке карточка станет зелёной.
3. Выберите офлайн-профиль: карточка должна показывать «Офлайн-профиль», без заявления о лицензии.
4. Проверьте профиль без Java Edition: должен показываться отдельный статус «Лицензия не обнаружена».
5. Отключите интернет и повторите проверку: ошибка соединения не должна означать, что лицензия отсутствует.

## Важное ограничение

Карточка не создаёт и не выдаёт лицензию. «Лицензия подтверждена» выставляется только после успешного получения профиля через Minecraft Services. Полную сборку в этой среде выполнить не удалось, потому что .NET SDK недоступен; проверены XML-разметка и соответствие имён элементов коду.
